À propos

Wolof Njaay Neena

Wolof Njaay Neena est une application dédiée aux léebu, les proverbes wolof transmis de génération en génération. Elle en rassemble plus de 2 700 pour les lire, les garder et les partager.

Comment ça marche

Chaque jour, un léebu est mis en avant. Le bouton « Nouvelle » vous en propose d'autres sans répétition jusqu'à ce que vous les ayez tous parcourus — votre progression reste sur cet appareil, sans compte ni serveur.

Application installable

Depuis le menu de votre navigateur, choisissez « Ajouter à l'écran d'accueil » (ou utilisez le bouton d'installation proposé) pour ouvrir Wolof Njaay Neena comme une application, avec un accès hors ligne.

Origine du projet

Adapté du projet original pafndio/wolof-njaay-neena, pour préserver et partager le patrimoine oral wolof du Sénégal. Code sous licence MIT.

Installer sur iPhone

  1. Touchez le bouton Partager (carré avec une flèche) dans la barre de Safari.
  2. Faites défiler et choisissez Sur l'écran d'accueil.
  3. Touchez Ajouter : Wolof Njaay Neena apparaît comme une application.
